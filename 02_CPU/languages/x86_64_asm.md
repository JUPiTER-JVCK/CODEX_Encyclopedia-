# x86-64 Assembly — language profile

> 64-bit successor to IA-32. Two textual flavors: **Intel** (NASM/MASM) and
> **AT&T** (GNU `as`/`gcc`). Same instructions, different mnemonic order:
> Intel = `dst, src`, AT&T = `src, dst` with `%` register prefix and `$`
> immediate prefix.

## Registers (64-bit / 32 / 16 / 8)

| 64 | 32 | 16 | 8 (low) | 8 (high — legacy) | Role / convention (System V) |
|----|----|----|---------|-----------------|------------------------------|
| `rax` | `eax` | `ax` | `al` | `ah` | Return value (low); accumulator |
| `rbx` | `ebx` | `bx` | `bl` | `bh` | Callee-saved |
| `rcx` | `ecx` | `cx` | `cl` | `ch` | 4th arg (SysV) / 1st arg (Win) |
| `rdx` | `edx` | `dx` | `dl` | `dh` | 3rd arg (SysV) / 2nd arg (Win) |
| `rsi` | `esi` | `si` | `sil` | — | 2nd arg (SysV) |
| `rdi` | `edi` | `di` | `dil` | — | 1st arg (SysV) |
| `rbp` | `ebp` | `bp` | `bpl` | — | Frame pointer (callee-saved) |
| `rsp` | `esp` | `sp` | `spl` | — | Stack pointer |
| `r8`–`r15` | `r8d`–`r15d` | `r8w`–`r15w` | `r8b`–`r15b` | — | r8/r9 = 5th/6th SysV args; r12-r15 callee-saved |
| `rip` | — | — | — | — | Instruction pointer (RIP-relative addressing) |
| `xmm0`–`xmm15` (128) | `ymm0`–`ymm15` (256) | `zmm0`–`zmm31` (512) | — | — | SSE/AVX/AVX-512 vectors |
| `rflags` | — | — | — | — | Status flags (`ZF`, `CF`, `SF`, `OF`, ...) |

## Common instructions

| Instruction | Effect |
|-------------|--------|
| `mov dst, src` | Move |
| `lea dst, [expr]` | Load effective address (no memory access) |
| `add / sub / imul / idiv` | Arithmetic |
| `and / or / xor / not` | Bitwise |
| `shl / shr / sar / sal / rol / ror` | Shifts/rotates |
| `cmp a, b` then `je / jne / jl / jg / jle / jge / jb / ja` | Compare + conditional jump |
| `test a, b` | `a & b`, sets flags only |
| `jmp label` | Unconditional jump |
| `call func` | Push return address + jump |
| `ret` | Pop return address + jump |
| `push / pop` | Stack ops (8-byte aligned by default) |
| `nop` | No-op |
| `syscall` | Enter kernel (Linux SysV) |
| `int 0x80` | Legacy 32-bit syscall |
| `cmov<cc>` | Conditional move (branchless) |
| `setcc al` | Set byte to 1/0 based on condition |
| SIMD: `movdqa`, `paddd`, `pmuludq`, `pshufb` | SSE2+ |
| AVX: `vmovaps`, `vfmadd231ps`, `vbroadcastss` | AVX/AVX2 |

## Calling conventions

### System V AMD64 (Linux/macOS/BSD)
- **Args (int/ptr)**: `rdi, rsi, rdx, rcx, r8, r9`, then stack
- **Args (float)**: `xmm0`–`xmm7`
- **Return**: `rax` (and `rdx` for 128-bit), `xmm0`/`xmm1` for floats
- **Caller-saved**: `rax, rcx, rdx, rsi, rdi, r8-r11, xmm*`
- **Callee-saved**: `rbx, rbp, r12-r15`
- **Stack 16-byte aligned** at call site
- **Red zone**: 128 bytes below `rsp` you can use without adjusting it (leaf fns)

### Microsoft x64 (Windows)
- **Args**: `rcx, rdx, r8, r9`, then stack
- **Shadow space**: caller reserves 32 bytes before call
- **Callee-saved**: `rbx, rbp, rdi, rsi, r12-r15, xmm6-xmm15`

### Linux syscall ABI
- **Number** in `rax`
- **Args**: `rdi, rsi, rdx, r10, r8, r9` (note `r10` instead of `rcx`!)
- **Return** in `rax` (negative = `-errno`)
- **Clobbers**: `rcx, r11`

## "Hello, world" (Linux, NASM Intel)

```nasm
; nasm -felf64 hello.asm && ld hello.o -o hello && ./hello
        global  _start
        section .data
msg:    db      "hello", 10
len:    equ     $ - msg

        section .text
_start:
        mov     rax, 1          ; sys_write
        mov     rdi, 1          ; stdout
        mov     rsi, msg
        mov     rdx, len
        syscall

        mov     rax, 60         ; sys_exit
        xor     rdi, rdi
        syscall
```

## "Hello, world" (Linux, GNU `as` AT&T)

```gas
        .globl  _start
        .data
msg:    .ascii  "hello\n"
len     = . - msg

        .text
_start:
        movq    $1, %rax
        movq    $1, %rdi
        leaq    msg(%rip), %rsi
        movq    $len, %rdx
        syscall

        movq    $60, %rax
        xorq    %rdi, %rdi
        syscall
```

## Inline assembly in C (Linux/GCC, AT&T)

```c
unsigned long rdtsc(void) {
    unsigned int lo, hi;
    __asm__ volatile ("rdtsc" : "=a"(lo), "=d"(hi));
    return ((unsigned long)hi << 32) | lo;
}
```

## Toolchain

| Tool | Use |
|------|-----|
| `nasm -felf64 file.asm` | NASM assembler (Intel syntax) |
| `gas` / `as` | GNU assembler (AT&T default; `--64` or `-msyntax=intel`) |
| `ld file.o -o app` | GNU linker |
| `objdump -d -M intel app` | Disassemble in Intel syntax |
| `objdump -d app` | Disassemble in AT&T |
| `gcc -S file.c -masm=intel` | Compiler output as Intel asm |
| `gdb -tui` then `layout asm` | Source/asm split |
| `radare2 / rizin / Ghidra / IDA / Binary Ninja` | Reverse engineering |
| `perf annotate` | Per-instruction hotspots |

## Common gotchas

- **Direction of operands** — Intel `mov dst, src` vs AT&T `mov src, dst`.
- **Sizes**: writing to `eax` zero-extends into `rax`; writing to `ax`/`al` does **not** (preserves upper bits).
- **`lea` is for arithmetic too** — `lea rax, [rdi + rsi*4 + 8]` computes without touching memory.
- **`xor reg, reg`** is the canonical "zero a register" — shorter encoding than `mov reg, 0`.
- **Stack alignment** — must be 16-byte aligned before `call` (SysV). Allocate a multiple of 16 in prologue.
- **Red zone use**: don't use it in signal handlers / kernel code (`-mno-red-zone`).
- **RIP-relative addressing** — use it for position-independent code (`lea rsi, [rel msg]`).
- **`movabs`** for 64-bit immediate-to-register; otherwise immediates are 32-bit sign-extended.
